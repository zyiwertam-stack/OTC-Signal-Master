# OTC-Signal-Master
OTC Scan Master — интеллектуальный AI-сканер для платформы Pocket Option. Анализирует скриншоты торговых графиков, распознаёт свечные модели, определяет направление рыночного движения и генерирует торговые сигналы CALL/PUT. Поддерживает OTC-валютные пары, настройку времени экспирации и интеллектуальный технический анализ рынка.
